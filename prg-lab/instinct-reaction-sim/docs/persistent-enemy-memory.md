# Persistent Enemy Memory

Persistent Enemy Memory は、倒されずに逃げ延びた敵をセーブデータに残し、再遭遇時の行動や成長に反映するための設計メモです。

## 基本方針

敵は一度きりの消費オブジェクトではなく、プレイヤーとの遭遇履歴を持つ存在として扱います。

通常戦闘で逃げ延びた敵や、プレイヤーが意図的に見逃した敵は、必要に応じてセーブデータへ保存されます。保存された敵は、次回以降の遭遇で過去の経験を参照し、行動や警戒度を変化させます。

## 保存される敵

保存対象の候補:

- 戦闘から逃げ延びた敵
- プレイヤーから大きなダメージを受けたが生存した敵
- プレイヤーを倒しかけた敵
- プレイヤーに何度も遭遇した敵
- 特殊なイベントや場所で出会った敵

すべての敵を保存するとデータが肥大化するため、保存対象は優先度で選別します。

## 遭遇ログによる成長

敵はプレイヤーとの遭遇ログをもとに成長します。

記録候補:

- 遭遇回数
- 逃走回数
- プレイヤーに受けたダメージ傾向
- プレイヤーがよく使う攻撃や戦術
- 恐怖、怒り、執着、復讐心
- 最後に遭遇した場所
- 最後に取った行動

このログは、敵の再登場時の行動決定やセリフ、配置、逃走判断に利用できます。

## 再登場時の行動変化

保存された敵は、再登場時に以前と同じ反応をするとは限りません。

変化例:

- プレイヤーを恐れて距離を取る
- 以前より早く逃げる
- 仲間を連れてくる
- 待ち伏せする
- プレイヤーの得意行動を避ける
- 復讐心から攻撃的になる
- 降伏や交渉を試みる

これにより、敵もプレイヤー固有の物語を持つ存在になります。

## 保存数上限と保存優先度

セーブデータには保存数上限を設けます。

優先度に使える指標:

- 遭遇回数が多い
- プレイヤーへの影響が大きい
- 逃走成功回数が多い
- プレイヤーとの因縁が強い
- 成長段階が高い
- 名前付き化している
- クエストや地域に関係している

優先度の低い敵は、時間経過や保存数上限によって削除、統合、または要約されます。

## 名前付き・中ボス化

同じ敵を何度も逃がすと、名前付きの個体として昇格する可能性があります。

昇格条件の例:

- 一定回数以上プレイヤーから逃げ延びた
- プレイヤーに強い恐怖や怒りを持った
- 特定地域で繰り返し出現した
- 仲間を失った、または仲間を率いるようになった
- プレイヤーに傷跡や固有の記憶を残した

名前付き化した敵は、通常敵よりも高い保存優先度を持ち、将来的には中ボス、復讐者、地域の脅威として扱えます。
